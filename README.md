# SeraphTube

SeraphTube is a desktop YouTube wrapper built with Rust and Tauri. It's designed to provide a simple, clean way to use YouTube on your desktop without having to keep a browser open. ⚠️**BUILT FOR MACOS ONLY!! (Planning to make a windows and linux version in the future)**

The idea behind SeraphTube is to take the YouTube experience and make it feel more like its own desktop application. It focuses on keeping things lightweight, easy to use, and customizable without adding a bunch of unnecessary clutter.

### Features

- **Native Network-Level Ad Blocking:** Blocks ads at the network level rather than relying on traditional browser extensions.
- **Built-in Themes:** Comes with 3 built-in themes so you can change the look of the app.
- **Custom Themes:** Download and install additional community-made themes to customize SeraphTube even further.
- **Desktop Experience:** Use YouTube in its own desktop window instead of a regular browser tab.
- **Rust & Tauri:** Built using Rust and Tauri to provide a lightweight desktop application.
- **Customization:** More options to personalize the app and make it your own.
